# 🌿 Сайт Массажной Студии с онлайн-записью (Python / FastAPI)

## 📁 Структура проекта

```text
site/
├── app/                        # Основной пакет приложения
│   ├── __init__.py
│   ├── main.py                 # Точка входа в приложение (FastAPI, подключения, демо-данные)
│   ├── config.py               # Конфигурация (переменные окружения, БД, секретные ключи)
│   ├── database.py             # Настройка подключения к базе данных (SQLAlchemy)
│   │
│   ├── models/                 # Модели базы данных (ORM)
│   │   ├── __init__.py
│   │   └── booking.py          # Таблицы: Услуги (Service), Мастера (Master), Записи (Booking)
│   │
│   ├── schemas/                # Pydantic схемы (валидация данных API)
│   │   ├── __init__.py
│   │   └── booking.py          # Валидация входных данных для бронирования
│   │
│   ├── api/                    # REST API эндпоинты (для AJAX-запросов и онлайн-записи)
│   │   ├── __init__.py
│   │   └── bookings.py         # Эндпоинты создания и получения записей
│   │
│   ├── views/                  # Маршруты для отображения HTML-страниц (Server-Side Rendering)
│   │   ├── __init__.py
│   │   └── routes.py           # Страницы: Главная, Онлайн-запись, Админка
│   │
│   ├── static/                 # Статические файлы сайта
│   │   ├── css/
│   │   │   └── main.css        # Дизайн-система (цвет, сетки, карточки, формы)
│   │   ├── js/
│   │   │   └── booking.js      # AJAX-отправка формы записи без перезагрузки
│   │   └── img/                # Фотографии и изображения
│   │
│   └── templates/              # HTML-шаблоны Jinja2
│       ├── base.html           # Базовый макет сайта (шапка, подвал)
│       ├── index.html          # Главная страница (услуги и специалисты)
│       ├── booking.html        # Форма записи
│       └── admin/
│           └── dashboard.html  # Панель администратора со списком записей
│
├── .env.example                # Пример настроек окружения
├── .gitignore                  # Игнорируемые файлы Git
├── requirements.txt            # Зависимости Python
└── README.md                   # Описание проекта
```

## 💡 Почему выбрана именно такая структура?

1. **Разделение ответственности (Separation of Concerns):**
   * **`models/`** отвечают *только* за хранение данных в БД.
   * **`schemas/`** отвечают *только* за валидацию того, что присылает пользователь (защита от некорректных данных).
   * **`api/`** содержит бизнес-логику обработчиков (REST API).
   * **`views/`** отвечает за генерацию и показ HTML страниц.

2. **Модульность и масштабируемость:**
   * Если завтра потребуется добавить онлайн-оплату, интеграцию с Telegram-ботом или рассылку SMS-напоминаний, для этого легко создать отдельные модули (например, `app/services/notifications.py`).

3. **Разделение API и Frontend:**
   * Форма записи отправляет данные через **REST API (`/api/bookings/`)** при помощи JavaScript (`booking.js`). Это делает интерфейс быстрым (без перезагрузки страницы) и позволяет легко подключить мобильное приложение в будущем к этому же API.

4. **Чистый фронтенд без громоздких сборщиков:**
   * CSS и JS файлы структурированы в `static/`, а шаблоны HTML используют наследование Jinja2 (`base.html`), что устраняет дублирование кода шапки и подвала.

## 🚀 Как запустить проект

1. Создать и активировать виртуальное окружение:
```bash
python3 -m venv venv
source venv/bin/activate
```

2. Установить зависимости:
```bash
pip install -r requirements.txt
```

3. Запустить сервер разработчика:
```bash
uvicorn app.main:app --reload
```

4. Открыть в браузере: `http://127.0.0.1:8000`
